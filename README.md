# Restaurant Management System

A simple Python-based Restaurant Management System with a graphical user interface.

## Features

- Restaurant order management
- User-friendly GUI
- Order data stored in CSV file
- Restaurant logo included
- Output screenshots included

## Technologies Used

- Python
- Tkinter
- CSV
- PIL (Pillow)

## Project Files

- `restaurant.py` – Main Python program
- `orders.csv` – Stores order data
- `logo.jpeg` – Restaurant logo
- `output.png` – Project output screenshot
- `output1.png` – Project output screenshot
- `output2.png` – Project output screenshot

## How to Run

1. Install Python.
2. Install required libraries.
3. Open `restaurant.py`.
4. Run the Python program.
